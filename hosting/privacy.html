Privacy & Security Policy — Helicopter War

Package Name: com.hellwar.game  |  Developer: GPT Game Studio  |  Effective Date: November 2026

Zero-Trust Owner-Only Access Policy: Players have no access to any other player's data, global user lists, Cloud Firestore security rules, backend administration, or project infrastructure. Administrative control belongs exclusively to the verified project owner account, and authenticated players can access only their own scoped game record (users/{uid}).

1. Strict Owner-Account-Only Access Rules

  • Backend & Security Rules Administration: Only the official project owner account has administrative permissions over Firebase configuration, Cloud Firestore Security Rules, AdMob settings, and GitHub deployment secrets. Players cannot view, modify, or bypass security rules.
  • Per-Player Account Isolation (request.auth.uid == userId): An authenticated player may only read and write strictly within their own users/{uid} profile and campaign subcollections. Listing other accounts, reading another player's progress, or deleting server ledgers is permanently denied at the database rules layer.
  • Zero Unauthenticated Database Access: Unauthenticated callers are denied all reads and writes by default (allow read, write: if false).

2. Information We Collect

  • Google Sign-In / Firebase Authentication: When you sign in with Google, we store your Firebase User ID (UID) and pilot callsign strictly to bind your game progress to your own account.
  • Cloud Firestore Game Data: Stores only your own War Credits, high score, destroyed enemy barracks records, and Empire Headquarters victories.
  • Google AdMob SDK: Displays Banner, Interstitial, and optional Rewarded Video ads. Google AdMob may process the Android Advertising ID and ad diagnostics under Google's Privacy Policy.

3. Data Security & Deletion

All network communication uses HTTPS/TLS encryption and zero-trust Cloud Firestore rules isolate records per authenticated UID. To request deletion of your account data, contact the project owner at benpasiglandingin@gmail.com.
